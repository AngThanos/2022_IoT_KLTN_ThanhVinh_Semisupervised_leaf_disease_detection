# YOLO_SEMI

Semi-supervised object detection training built on top of Ultralytics YOLO and PyTorch Distributed Data Parallel. The main training flow uses a student-teacher setup where the teacher is updated with EMA and produces pseudo-labels for unlabeled images.

## Features

- Semi-supervised training with labeled and unlabeled data
- EMA teacher for pseudo-label generation
- YOLO-style detection labels
- Distributed training support
- TensorBoard logging and CSV metrics export
- Simple baseline training script using standard Ultralytics YOLO

## Method overview

`train_semi.py` trains:

1. a **student** detector on labeled data,
2. an **EMA teacher** copied from the student,
3. pseudo-labels generated by the teacher on unlabeled images,
4. supervised loss + unsupervised pseudo-label loss.

Validation reports a detection F1 score computed from matched predictions and ground-truth boxes.

## Dataset format

The project expects YOLO detection labels in normalized format:

```text
class_id x_center y_center width height
```

Expected directory structure:

```text
data/data_yolo/
├── train/
│   ├── labeled/
│   │   ├── images/
│   │   ├── labels/
│   │   └── list.txt
│   └── unlabeled/
│       ├── images/
│       └── list.txt
└── val/
    ├── images/
    ├── labels/
    └── list.txt
```

### `list.txt` format

Each line should contain the image stem only, without extension. Example:

```text
DJI_20240112090308_0001_D
DJI_20240112090308_0002_D
```

The current dataset loader builds paths like:

- train labeled image: `labeled/images/<stem>.jpeg`
- train labeled label: `labeled/labels/<stem>.txt`
- validation image: `images/<stem>.jpeg`
- validation label: `labels/<stem>.txt`

## Configuration

Main experiment config: [exps/zrun_yolo/yolo_semi/config_semi.yaml](exps/zrun_yolo/yolo_semi/config_semi.yaml)

Key options:

- `dataset.train.batch_size`: batch size per process
- `dataset.n_sup`: number of supervised samples used by the loader
- `trainer.epochs`: total training epochs
- `trainer.sup_only_epoch`: warmup epochs before pseudo-label training
- `trainer.unsupervised.threshold`: pseudo-label confidence threshold
- `trainer.unsupervised.loss_weight`: unsupervised loss weight
- `net.num_classes`: number of object classes
- `net.encoder.pretrain`: pretrained YOLO checkpoint path
- `saver.auto_resume`: resume from last checkpoint if available

Current default config uses:

- `yolov8n.pt` as the pretrained backbone
- `num_classes: 2`
- `epochs: 100`
- `batch_size: 4`

## Training

### 1) Semi-supervised training

Single process:

```bash
python train_semi.py --config exps/zrun_yolo/yolo_semi/config_semi.yaml --seed 42
```

Distributed with `torchrun`:

```bash
torchrun --nproc_per_node=2 --master_port=29500 train_semi.py \
  --config exps/zrun_yolo/yolo_semi/config_semi.yaml \
  --seed 42
```

Using the launcher script:

```bash
bash run.sh exps/zrun_yolo/yolo_semi/config_semi.yaml 2 29500 42
```

### 2) Simple YOLO baseline

To train a standard Ultralytics YOLO model without semi-supervision:

```bash
python train_yolo_simple.py
```

This uses [data/data_yolo/data_yolo.yaml](data/data_yolo/data_yolo.yaml).

## Outputs

Training artifacts are written under [exps/zrun_yolo/yolo_semi](exps/zrun_yolo/yolo_semi):

- [exps/zrun_yolo/yolo_semi/checkpoints](exps/zrun_yolo/yolo_semi/checkpoints): latest and best checkpoints
- [exps/zrun_yolo/yolo_semi/log](exps/zrun_yolo/yolo_semi/log): log files and CSV metrics
- `events_seg/...`: TensorBoard event files

Typical checkpoint files:

- `ckpt.pth`: latest checkpoint
- `ckpt_best.pth`: best EMA-teacher checkpoint by validation score

## Monitoring

Launch TensorBoard from the project root:

```bash
tensorboard --logdir exps/zrun_yolo/yolo_semi/log/events_seg
```

## Notes

- The semi-supervised pipeline expects distributed launch even for one GPU because it initializes PyTorch distributed.
- Images are currently resolved with the `.jpeg` extension by the dataset loader.
- Validation is based on the custom logic inside [train_semi.py](train_semi.py), not Ultralytics' built-in evaluator.
